Prototype-7 (LifeRPG Technical Plan)
This document contains technology recommendations, database structure, and AI integration logic for
the LifeRPG application.

1. Tech Stack Recommendations
Here is a combination of modern technologies that offer fast performance and a great developer
experience:

A. Frontend (UI & Interaction)
Framework: React (with Vite).
Reason: Extensive ecosystem, highly responsive for interactive applications like games.
Language: TypeScript.
Reason: Avoids data type bugs, which is crucial when managing complex stats objects.
Styling: Tailwind CSS.
Reason: Speeds up custom UI creation. We can easily create "Cyberpunk" or "Fantasy" looks.
Animation: Framer Motion.
Reason: Essential for game-feel. Animations when stats increase (bars rising, numbers rolling)
make users feel satisfied.
Chart Library: Recharts or Chart.js.
Reason: We need a Radar Chart to visualize the Hexagon Stats.

B. Backend & Database (Infrastructure)
Core: Supabase.
Auth: Handles Google/Email login easily.
Database: PostgreSQL (very strong for user data relations).
Realtime: Supabase subscription features allow stats to update on screen without refreshing
if you develop multiplayer/leaderboard features later.

C. Artificial Intelligence (Brain)
Model: Google Gemini API (via Google AI Studio).
Model Variant: gemini-2.5-flash (recommended).
Reason: Flash is very fast and cost-effective (even free in certain tiers), suitable for short text
analysis requiring quick responses so users don't wait long.

2. Data Structure (Database Schema)
Since we are using Supabase (PostgreSQL), here is the table design:
Table: users
(Handled by Supabase Auth, but we can create a public profiles table)
id (uuid, PK)
username (text)
avatar_url (text)
level (int, default: 1)
current_exp (int, default: 0)

Table: user_stats (Hexagon Stats)
user_id (uuid, FK)
strength (int) - Health/Physical
intelligence (int) - Learning/New Skills
charisma (int) - Social/Networking
creativity (int) - Arts/Ideas/Problem Solving
wisdom (int) - Mental Health/Faith/Reflection
wealth (int) - Finance/Career (Values 0-100 or uncapped depending on the leveling system)

Table: activity_logs
id (uuid)
user_id (uuid)
description (text) - User journal input
ai_analysis (jsonb) - Gemini analysis result
created_at (timestamp)

3. AI Logic Flow (Gemini Workflow)
The most critical part is converting "Stories" into "Numbers". We must force Gemini to return a JSON
format.
System Prompt for Gemini:
"You are an RPG Game Master. The user will share their achievements or activities for the
day. Your task is to analyze the story and award experience points (XP) to the following 6
attributes: STR (Physical), INT (Intelligence), CHA (Social), CRE (Creativity), WIS (Wisdom),
WEA (Wealth).
Provide the response ONLY in JSON format: { "summary": "Short RPG-style summary
(example: 'You successfully conquered the coding bug!')", "stats_increase": { "STR": 0,
"INT": 5, "CHA": 0, "CRE": 2, "WIS": 0, "WEA": 0 }, "xp_gained": 20 }"

Use Case Example:
1. User Input: "Today I presented to a client and closed a deal worth 10 million, but I feel really
exhausted."
2. Gemini Analysis:
Presentation & Deal -> CHA +5, WEA +10.
Exhausted -> Maybe STR -1 (optional) or no effect.
3. Frontend: Displays an animation of numbers increasing +10 on the Wealth chart.
4. Additional Gamification Features (Development Ideas)
To improve user retention:
1. Level Up System: If total stats reach a certain number, the User Level increases.
2. Titles/Achievements:
If STR > 80: Title "Gym Rat" unlocked.
If INT > 80: Title "Sage" unlocked.
3. Quests: AI can generate "Daily Quests" based on the user's weakest stats.
Example: User's Social stats are low. Today's Quest: "Greet a neighbor or an old friend."

5. Development Roadmap
1. Phase 1 (Setup): Init React project & Setup Supabase Project.
2. Phase 2 (Auth & UI): Create Login page & Dashboard with Radar Chart (Dummy Data).
3. Phase 3 (AI Integration): Create function to send text to Gemini API and parse JSON response.
4. Phase 4 (Database Sync): Save Gemini response results to Supabase user_stats table.
5. Phase 5 (Polishing): Add particle animations, level up sound effects, and mobile responsiveness
